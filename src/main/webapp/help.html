    Help & Instructions

    Step-by-step guide for using the system

    Managing Appointments

    1. First, register the patient in Patient Management
    2. Note the patient ID (e.g., P001)
    3. Go to Appointments page
    4. Enter the patient ID and search
    5. Select dentist and treatment type
    6. Choose appointment date and time
    7. Click Register Appointment

    Patient Registration

    1. Go to Patient Management page
    2. Click Register Patient tab
    3. Fill in patient details:
      • Patient Name (required)
      • Contact Number (required)
      • Email (optional)
      • Other details (optional)
    4. Click Register Patient
    5. System will generate a Patient ID (e.g., P001)
    6. Patient will receive email confirmation

    Billing Process

    1. Go to Billing page
    2. Enter the appointment number
    3. Click Calculate to preview bill
    4. Review:
      • Treatment Cost
      • Consultation Fee
      • Discount (if applicable)
      • Total Amount
    5. Click Generate Bill
    6. Select payment method
    7. Click Process Payment
    8. Click Print Bill for receipt

    Reports

    1. Go to Reports page
    2. Select report type:
      • Summary: Overall statistics
      • Daily: Appointments for a day
      • Revenue: Financial analysis
    3. Set date range
    4. Click Generate

    Security Guidelines

    • Never share your password
    • Always log out when leaving
    • Use strong passwords
    • Report suspicious activity
    • Don't leave sessions open
