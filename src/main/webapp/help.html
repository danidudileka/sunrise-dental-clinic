Help & Instructions

Step-by-step guide for using the system

📅 Managing Appointments

  1. Navigate to the Appointments page from the menu
  2. Click on the Register Appointment tab
  3. Fill in the patient details:
    • Patient Name (required)
    • Contact Number (required)
    • Address (optional)
    • Email (optional)
  4. Select the dentist from the dropdown
  5. Select the treatment type
  6. Choose appointment date and time
  7. Click Register Appointment

Searching for an Appointment

  1. Go to the Appointments page
  2. Click on the Search Appointment tab
  3. Enter the appointment number (e.g., APT202400001)
  4. Click Search to view details

💳 Billing Process

  1. Navigate to the Billing page
  2. Enter the appointment number
  3. Click Calculate to preview the bill
  4. Review the bill details:
    • Treatment Cost
    • Consultation Fee
    • Discount (if applicable)
    • Total Amount
  5. Click Generate Bill to create the bill
  6. Select payment method
  7. Click Process Payment
  8. Click Print Bill for a physical copy

📈 Generating Reports

  1. Go to the Reports page
  2. Select report type:
    • Summary Report: Overview of all activities
    • Daily Appointments: Appointments for a specific day
    • Revenue Report: Revenue analysis
  3. Set the date range
  4. Click Generate
  5. Review the report results

🔐 Security Guidelines

  • Never share your password with others
  • Always log out when leaving your workstation
  • Use strong passwords (minimum 8 characters)
  • Report any suspicious activity to the administrator
  • Do not leave your session open on shared computers
